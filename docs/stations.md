# 주유소 데이터 (places.csv)

`tools/build_places.py`로 만든 결과입니다. 오피넷 공개 다운로드의 전국 주유소 10,315곳 중 **4,003곳(38.8%)**에 실제 위치를 붙였습니다. 이름·상표·셀프 여부·가격은 모두 오피넷 원본 그대로입니다.

| 위치를 찾은 방법 (확실한 순) | 곳 |
|---|---|
| 오피넷 API 공식 좌표 | 296 |
| 같은 시군구, 같은 이름의 OSM 주유소 | 1,795 |
| 고속도로: 같은 이름·방향의 OSM 휴게소 (안의 주유소) | 116 |
| 같은 시군구, 같은 도로명주소의 OSM 건물 | 529 |
| 같은 도로(100 m 이내)의 OSM 주유소 | 920 |
| 같은 도로·같은 쪽 건물번호 보간 | 347 |

3·4번 방식의 정확도: 이름으로 위치가 확실한 곳에 같은 방식을 써 보고 실제 자리와 거리를 쟀습니다.

| 방식 | 시험한 곳 | 중앙값 | 80% | 90% | 정확히 같은 주유소 (≤ 30 m) |
|---|---|---|---|---|---|

보간한 자리 150 m 안에 OSM 주유소가 있으면 그 자리로 옮깁니다. 고속도로 휴게소는 양쪽이 같은 이름일 때 휴게소 옆 차로가 방향 도시(예: "(부산)"의 부산) 쪽으로 가는 곳을 고릅니다. 이름에 방향이 적힌 OSM 휴게소로 이 판정을 시험하면 38/38곳이 맞습니다.

오피넷과 이어지지 않은 OpenStreetMap 주유소 2,901곳도 실제 자리 그대로 넣었습니다 (오피넷 주유소 100 m 안에 있는 것은 같은 곳으로 보고 뺌). 앱에는 "가격 정보 없음"으로 나오고, 긴급 자동 경유지는 오피넷에서 확인된 주유소를 먼저 고릅니다.

가격은 오피넷 "사업자별 현재 판매가격" 내려받은 날 기준입니다 (앱 화면에 기준일 표시). 위치를 못 찾은 오피넷 주유소는 틀린 자리에 두지 않으려고 뺐습니다. 도로 시작점에서 번호 × 10 m로 놓는 방식과 시군구 안 상표 소거 방식도 시험했지만 오차가 수 km라 쓰지 않았습니다.
